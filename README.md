# NUSA Apps (PWA)

Aplikasi NUSA versi Web App / Progressive Web App.

## Fitur
- Home Dashboard
- NUSA Wallet
- Discover UMKM
- NUSA Rewards
- QR Merchant Demo
- Profile
- LocalStorage untuk menyimpan saldo demo

## Upload ke GitHub
Buat folder `apps` pada repository, lalu upload seluruh isi folder ini:

apps/
├── index.html
├── manifest.json
├── sw.js
└── README.md

URL:
https://dedeirawansab-code.github.io/nusa-network/apps/
